Using a course in the port

Save as courseN.bin into mods/<your mod>/courses/ beside the game. N is the course table index: Stadium 1 courses 1–4 are 0–3, Stadium 2 courses 1–4 are 4–7 (in the Gen A build; in the Gen B build 0–3 are Stadium 3 and 4–7 Stadium 4), 8 and 9 the special courses. The file is one byte per track column, up to 4088 columns. See docs/MODDING.md.
